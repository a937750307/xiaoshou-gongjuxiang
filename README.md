# 销售工具箱

一个给汽车销售用的轻量效率工具集合。纯前端单文件，双击浏览器即可打开，无需联网、无需安装、无需账号，所有数据保存在本机浏览器。

## 背景

从 4S 店企划转销售后，需要一套顺手的工具把客户经营、报价、讲解和日常事务管起来。原则是：**厂家系统里已有的功能不重复做**（客户跟进、活动转化等交给厂家系统），这里只保留个人真正用得上、厂家系统不提供的工具。

## 功能

目前包含 4 个模块：

### 1. 智能算价器
- 车型价格库：录入品牌、车型、配置、指导价、参考优惠，选择车型一键带入
- 费用明细：裸车价、购置税（按比例/免税/手填）、保险、上牌、装潢、其他，实时算落地价
- 贷款测算：首付比例、年限、利率，支持等额本息与等额本金，算月供和总利息
- 报价单：生成可打印的报价单，或复制报价文本发微信
- 方案收藏：常用报价存起来，下次一键载入继续改

### 2. 话术速查
- 67 条话术，18 个分类，按标准销售流程排序：
  线上响应 → 邀约（首邀三件套、短信） → 需求探询 → 到店接待 → 静态讲解 → 产品亮点 → 品牌宣传 → 竞品对比与攻防 → 试驾提示 → 异议应对 → 金融政策 → 活动政策 → 成交促单 → 交车售后 → 到家关怀 → 营销文案
- 每条分两部分，样式区分：
  - **做法**（灰底）：策略思路、为什么这么说
  - **话术**（蓝底）：可直接对客户说的原话，一键复制
- 支持分类筛选、关键词搜索、增删改、恢复默认话术库

### 3. 个人提成计算器
- 提成规则：月底薪、按车型的单车提成、金融每台提成、保险/精品提成比例、销量阶梯奖金
- 成交明细：每成交一台记一条（日期、车型、是否金融、保险额、精品额）
- 自动汇总：底薪 + 单车 + 金融 + 保险 + 精品 + 阶梯奖金 = 税前收入，按所选月份统计
- 可复制收入明细

### 4. 事件提醒器
- 记录个人要办的杂事（交资料、回访、开会等），不与厂家系统的客户跟进重复
- 统计今日待办 / 逾期 / 未来 7 天 / 已完成
- 逾期标红、分类筛选、勾选完成、清除已完成
- 侧栏红色角标提醒今日 + 逾期条数

## 使用方式

1. 直接用浏览器打开 `index.html`（推荐 Chrome / Edge）
2. 首次打开会带示例数据（示例车型、话术、待办），按自己的实际情况替换即可
3. 侧栏顶部可切换行业（当前仅"汽车行业"）
4. 顶部"导出备份"下载 JSON 文件，"导入"恢复——换电脑或清理浏览器前务必导出

## 数据存储

- 全部数据保存在浏览器 `localStorage`，键名 `salesToolbox_v1`
- 不上传任何服务器，不联网也能用
- 换浏览器、清缓存、无痕模式都会导致数据丢失，请定期导出备份
- 导入旧版本数据会自动升级到新结构，自己新增/编辑的话术会保留

## 技术说明

- 单个 HTML 文件，内联 CSS 和原生 JavaScript，零依赖
- 数据层统一：`localStorage` + JSON 导入导出
- 响应式布局：PC 端多栏，手机端自动调整为单栏，备案信息手机端分三行居中
- 底部含备案信息（本站内容仅供学习和交流，非商业用途；浙ICP备2025187466号；浙公网安备33030402001483号）
